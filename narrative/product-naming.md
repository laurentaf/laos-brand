# Product Naming — Justificativa dos Módulos

Cada nome carrega uma referência mitológica ou linguística que reforça a tese de inversão da marca. Nenhum nome é decorativo — cada um é uma decisão arquitetônica.

---

## Laurent Core

| | |
|---|---|
| **Referência** | *Laurent* — do latim *laurus* (louro). A coroa de louros usada por imperadores romanos, poetas laureados e vencedores. |
| **Função técnica** | Núcleo de orquestração. Compositor de capacidades LATADE, LAN8N, LADESIGN via MCP. Decide, roteia, delega. |
| **Por que não "Engine"** | Engine é força bruta — pistão, fogo, movimento. Core é centro de gravidade — o ponto em torno do qual tudo orbita. A tese não é sobre potência, é sobre soberania distribuída. Engine manteria o operador como consumidor de força; Core coloca o operador no centro. |

---

## Laós Layer

| | |
|---|---|
| **Referência** | *Laós* (λαός) — grego para "povo", "multidão", "a massa soberana" da polis. Oposto de *archon* (governante). |
| **Função técnica** | Runtime dos subagentes. Camada onde os agentes são spawnados, executados e monitorados. Estrato democrático de operação. |
| **Por que não "Runtime"** | Runtime é tecnicamente preciso mas narrativamente vazio — todo sistema tem um. Laós Layer carrega a tese: a soberania não está no núcleo, está na camada. Runtime soa como utilidade; Layer soa como jurisdição. |

---

## Talos Mesh

| | |
|---|---|
| **Referência** | *Talos* — primeiro autômato da história ocidental. Gigante de bronze forjado por Hefesto para guardar Europa em Creta. Miticamente, o primeiro robô. |
| **Função técnica** | Camada distribuída de integridade: observabilidade, qualidade de dados, verificação de execução, monitoramento. Não um guardião único, mas uma malha de checagens. |
| **Por que não "Guard"** | Guarda implica perímetro — uma muralha, um portão, um ponto único de falha. Talos na mitologia era sentinela, sim, mas a virada é que LAOS pega o primeiro autômato e o transforma em arquitetura, não em segurança perimetral. Mesh é distribuído, resiliente, em todo lugar — como Talos deveria ter sido. |

---

## The Oracle

| | |
|---|---|
| **Referência** | *Oráculo de Delfos* — a Pítia entregava profecias. Em teoria acessível a qualquer cidadão; na prática, capturada pelo poder. |
| **Função técnica** | Inteligência preditiva: forecasting, detecção de anomalias, geração de insights. Um serviço — não um soberano. |
| **Por que não "AI"** | "AI" é uma commodity narrativa. Diz o quê, não o como nem o onde. The Oracle nomeia a função (inteligência preditiva) e a posição (serviço, não soberano). O nome carrega um aviso: oráculos podem ser capturados pelo poder — este foi projetado para não ser. |

---

## The Forum

| | |
|---|---|
| **Referência** | *Fórum Romano* — praça pública de deliberação, comércio, lei e assembleia. Espaço onde o laós agia, não apenas recebia. |
| **Função técnica** | Superfície de colaboração humana: conversas, decisões, aprovações, retrospectivas. Interface endereçável para operadores. |
| **Por que não "Dashboard"** | Dashboard é somente leitura. Você vê — não age. O Fórum é leitura e escrita. Dashboards mostram; Fóruns deliberam. Um é passividade; o outro é agência. O nome escolhe agência. |
